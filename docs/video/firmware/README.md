# Vídeos por firmware UV-K5 V3 / Firmware videos

**ES** — Un vídeo por firmware Bricohams del catálogo (`bricohams-fusion`, `-labs`, `-ardf`, `-satellite`, `-spectrum`). **No son capturas del hardware ni de un emulador del firmware**: son recreaciones etiquetadas en pantalla, generadas con `scripts/build-firmware-videos.py` solo a partir de datos verificados de `precompiled/catalog.json` (tamaño, SHA-256, opciones, módulos). Subtítulos incrustados y `.srt` en es/en/de/fr/it (sin voz). Los firmwares siguen en Beta, sin prueba de arranque en hardware.

**EN** — One video per catalog Bricohams firmware. **They are not captures of hardware or of a firmware emulator**: they are on-screen-labelled recreations built by `scripts/build-firmware-videos.py` only from verified `precompiled/catalog.json` data (size, SHA-256, options, modules). Embedded subtitles and `.srt` in es/en/de/fr/it (no voice-over). Firmware remains Beta, not boot-tested on hardware.
