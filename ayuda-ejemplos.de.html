Quelle: offizielle Releases von armel/uv-k1-k5v3-firmware-custom und muzkr/moto. Die SHA-256-Werte stimmen mit den von GitHub für jede Datei veröffentlichten Werten überein. Vor der Verwendung prüfen:

cd examples/firmware/f4hwn-v6.3.0
sha256sum -c SHA256SUMS

Firmware der Hauptversion flashen: Inbetriebnahme von 0 bis 100 %. Die neueste Version findest du stets im armel-Release; diese Kopien sind eine feste Referenz.

Skripte

Eigener Bricohams-Code unter der Repository-Lizenz (GPL-3.0-or-later). Mit python -I ausführen.

SkriptFunktion
tg_kb.pyWandelt JSON-Exporte von Telegram Desktop aus technischen Gruppen in eine lokale thematische Wissensdatenbank (Firmware, Flashen, Kalibrierung, Mods) um, mit einem Dateikatalog (SHA-256, Ziel-MCU anhand der Vektortabelle) und Linkkatalog. Entfernt Autoren, Aliasse, Telefonnummern und E-Mail-Adressen. Das Ergebnis ist Material Dritter: lokal speichern
test_tg_kb.pyTest von tg_kb.py mit einem synthetischen Export: python -I test_tg_kb.py
check_repos.pyLiest eine Liste owner/repo und erstellt eine Tabelle mit Status, letztem Push, Lizenz, Sternen und MCU (V3/K1, falls PY32-Code vorhanden). Benötigt gh mit Sitzung
recover.pySucht für gelöschte Repositories nach einer Kopie in Software Heritage, einem Snapshot in Wayback Machine und Forks mit demselben Namen

Typische Verwendung:

python -I tg_kb.py salida ChatExport_grupo1 ChatExport_grupo2
python -I check_repos.py repos.txt > repos.md
python -I recover.py caidos.txt

Übersetzung des spanischen Originals. Bei Abweichungen gilt die spanische Fassung.
