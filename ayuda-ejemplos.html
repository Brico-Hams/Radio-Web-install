Origen: releases oficiales de armel/uv-k1-k5v3-firmware-custom y muzkr/moto. Los SHA-256 coinciden con los que publica GitHub para cada archivo. Comprobar antes de usar:

cd examples/firmware/f4hwn-v6.3.0
sha256sum -c SHA256SUMS

Flashear el firmware principal: puesta en marcha de 0 a 100 %. La version mas reciente esta siempre en la release de armel; estas copias son una referencia fija.

Scripts

Codigo propio de Bricohams, con la licencia del repositorio (GPL-3.0-or-later). Ejecutar con python -I.

ScriptQue hace
tg_kb.pyConvierte exportaciones JSON de Telegram Desktop de grupos tecnicos en una base de conocimiento local por temas (firmware, flasheo, calibracion, mods), con catalogo de archivos (SHA-256, MCU de destino por la tabla de vectores) y de enlaces. Elimina autores, alias, telefonos y correos. El resultado es material de terceros: guardarlo en local
test_tg_kb.pyPrueba de tg_kb.py con una exportacion sintetica: python -I test_tg_kb.py
check_repos.pyLee una lista owner/repo y saca una tabla con estado, ultimo push, licencia, estrellas y MCU (V3/K1 si hay codigo PY32). Necesita gh con sesion
recover.pyPara repos borrados: busca copia en Software Heritage, captura en Wayback Machine y forks con el mismo nombre

Uso tipico:

python -I tg_kb.py salida ChatExport_grupo1 ChatExport_grupo2
python -I check_repos.py repos.txt > repos.md
python -I recover.py caidos.txt
