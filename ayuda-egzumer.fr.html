Egzumer : sources, configuration et différences avec V3

Révision : 25-10-2026. Source inspectée : egzumer/uv-k5-firmware-custom, commit 7607f0a4bd6203d1f06b70556fc1ce0d7399d6b3.

Apports de ce dépôt

Il publie du code C, des en-têtes, un Makefile et la documentation d’une réimplémentation du firmware Quansheng UV-K5/K6/5R de la famille d’origine. Le README explique la provenance de DualTachyon, des modifications OneOfEleven et de l’analyseur fagci. Cette base n’est pas le portage PY32 pour UV-K5 V3/UV-K1.

Son fichier LICENSE contient Apache License 2.0, et non MIT. Conservez ses avis, attributions et ceux des composants lors d’une dérivation de code. La licence d’Egzumer ne prouve pas qu’une autre image appelée Karina utilise la même licence ni que les sources exactes de ce binaire sont disponibles.

N’utilisez pas un flasheur V1 ni une image Egzumer d’origine sur une V3. Les mots K5/K6 sur une page de garde ne prouvent pas la révision du MCU. Consultez la carte et le projet. Aucun compilateur Egzumer n’est intégré à la commande Bricohams V3.

Fonctions et réglages utilisateur

Le README documente la correction AM, la démodulation SSB, le spectre, le balayage rapide, la modification du nom, les modes d’affichage, les touches attribuables, la batterie, le rétroéclairage, le microphone et la recherche CTCSS/DCS. SSB désigne ici la démodulation en réception ; cela ne signifie pas un émetteur SSB.

Pour les notions RX/TX, step, largeur, SQL, tonalités, VOX, TOT et verrouillage de canal, consultez la configuration commune. Utilisez le nom du menu, et non des numéros transposés depuis F4HWN v6 ou Karina. L’ordre et les noms ont été modifiés par rapport au firmware stock.

Le wiki officiel est la référence pour les séquences de touches du build installé :

  • Wiki et manuel.
  • Releases.

Tous ses raccourcis n’ont pas été vérifiés sur le matériel et ils ne sont pas transférés automatiquement aux firmwares dérivés. Le README avertit des limites de plage dynamique, de la surcharge et des filtres d’entrée ; l’AM fix ne peut pas éliminer les limites physiques. Une antenne avec un signal plus fort peut dégrader la réception dans un environnement RF intense.

Dans ce Makefile, Clang force LTO=0 ; avec LTO=1, OVERLAY=0 est imposé. Ces règles sont propres à cette base et ne doivent pas être copiées dans le CMake PY32 sans analyse. L’activation d’options peut dépasser la mémoire ou casser des combinaisons ; l’existence d’une clé n’implique pas que toutes les combinaisons soient prises en charge.

Pour compiler, utilisez la toolchain et la procédure de son README dans un checkout fixé, conservez la carte mémoire, la licence et les hashs, et validez le matériel V1. Egzumer n’a pas été compilé, flashé ni testé lors de cet ajout documentaire.

Relation avec Karina et Bricohams

Une généalogie de fonctions similaires ne permet pas de reconstituer les sources exactes de Karina. Les pilotes et noms qui mentionnent Egzumer ne constituent pas non plus une preuve. Bricohams V3 dérive actuellement de F4HWN PY32, et non de ce dépôt d’origine. Un projet Bricohams V1 serait une autre compilation et une autre validation matérielle.
