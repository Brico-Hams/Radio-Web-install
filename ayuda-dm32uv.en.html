Baofeng DM-32UV: open firmware, OpenGD77, and how to build it

Revision: 26-10-2026. Research into source code and how to build firmware for the DM-32UV on GitHub, Codeberg, GitLab, GitFlic, the OpenGD77 website, and the Telegram groups OpenGD77 EA, Baofeng DM-32UV EA, Baofeng DM-32UV RU, and OpenGD77 Rus. Nothing in this guide has been tested on a Bricohams radio: each fact identifies its source.

Crossing families soft-bricks the radio: recover in update mode (PTT+SK1). BFUV32-V2 file: 256-byte header (BFUV32-V2 ... END) followed by the raw image linked at 0x0300C000. It is not encrypted or signed.

Step 0: backup

Before installing any firmware, back up both flash chips. They contain each radio's unique RX/TX calibration and ALPU key:

  • OpenUV008_Flasher_v1 by andynvkz (infotex58, topic 1155): radio off, click Read, turn it on when prompted. Repeat for the program flash and the data flash.
  • Alternative: the Python scripts at rogerclarkmelbourne/DM32.
  • grid.radio also offers browser-based Backup/Restore for both chips.
  • If a cable fails, try another USB-serial chip (CH340, FTDI, or CP2102). According to RadioFoundry, the HR_C7000 ROM responds only with FTDI.

Install OpenGD77 (experimental)

  1. Complete step 0 and save the files somewhere safe.
  2. Install OpenGD77 CPS E2026.05.26.01 or later (experimental downloads).
  3. Under Radio Type, choose DM32/UV008 and open Extras > Firmware loader.
  4. With the radio off, hold PTT + SK1 and turn it on. The green LED indicates update mode. Connect the cable.
  5. Choose the firmware (reference: OpenGD77_DM32_20260704.bin) and wait for it to finish.
  6. Write the default codeplug.
  7. To return to factory firmware, repeat with Baofeng firmware from its CPS in update mode.

Alternative with no installation: grid.radio with Chrome or Edge (Web Serial, no Zadig). Procedure source: xreflector.es guide (PDF).

According to the groups (August–October 2026): no stable version, low DMR audio, and various faults. It covers only the 01.* family. Authors: andynvkz (UV008 port), Koshak and RA4FHE (DM-32), Roger VK3KYY (CPS).

Build firmware: RadioFoundry

RadioFoundry is new, open DMR firmware (MIT, created 24-10-2026), with a shared core and a per-radio layer. It is not derived from OpenGD77 code. Releases are not published yet: you have to build it.

git clone https://github.com/RadioFoundry/RadioFoundry
cd RadioFoundry
git submodule update --init
tools/build-csky-toolchain.sh            # GCC csky-elf en ~/toolchains/csky-elf (unos 45 min)
make BOARD=dm32                          # build/dm32/rfoundry_dm32.bin
tools/hrc7000_codec.py --stock DM32.01.01.049.bin   # tu firmware de fabrica: anade el codec en local
tools/serial_loader.py --model dm32 build/dm32/rfoundry_dm32_codec.bin --wrap build/dm32/rfoundry_dm32_codec_BFUV32.bin
StepDetails
Toolchaintools/build-csky-toolchain.sh or Docker image tools/docker/csky-toolchain/run.sh make BOARD=dm32
Codectools/hrc7000_codec.py checks factory firmware by SHA-256 and copies the codec on your machine. It is never uploaded to the repository or shared. Without the codec, only FM works
Flashingtools/serial_loader.py speaks the Baofeng bootloader protocol (YMODEM at 115200). --wrap creates the BFUV32-V2 file for the official updater. --stock ARCHIVO returns to factory firmware
Migrate the codeplugRun tools/dm32_migrate.py all --image ... --dry-run first. It uses dmrconf from qdmr 0.15
SafetyRadioFoundry does not touch the bootloader or data flash below 0x700000
StatusIts own documentation says the flashing and migration tools have not been tested on a radio. Start with --dry-run, connect an antenna, and do not transmit until verified

Licenses and limits

  • RadioFoundry is MIT; current OpenGD77 prohibits commercial use; OpenDM32 does not publish source code. No code from incompatible licenses is mixed, and third-party firmware is not redistributed.
  • The AMBE codec is used only when extracted from the radio's own factory firmware.
  • Calibration and the ALPU key belong to each radio: do not copy them from another unit.
  • Transmit only on authorized bands, even if modified firmware allows it.

Bricohams also maintains a technical dossier and a C-SKY port skeleton in the private dm32uv-opengd77-port repository. The recommended route today is to build RadioFoundry.
