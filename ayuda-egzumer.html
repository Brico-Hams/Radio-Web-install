Egzumer: fuentes, configuracion y diferencias con V3

Revision: 25-10-2026. Fuente inspeccionada: egzumer/uv-k5-firmware-custom, commit 7607f0a4bd6203d1f06b70556fc1ce0d7399d6b3.

Que aporta este repositorio

Publica codigo C, cabeceras, Makefile y documentacion de una reimplementacion del firmware Quansheng UV-K5/K6/5R de la familia original. El README explica la procedencia de DualTachyon, modificaciones OneOfEleven y analizador fagci. Esta base no es el port PY32 para UV-K5 V3/UV-K1.

Su archivo LICENSE contiene Apache License 2.0, no MIT. Conservar sus avisos, atribuciones y los de los componentes al derivar codigo. La licencia de Egzumer no demuestra que otra imagen llamada Karina use la misma licencia ni que se disponga de las fuentes exactas de ese binario.

No usar un flasheador V1 ni imagen Egzumer original en una V3. Las palabras K5/K6 en una portada no prueban revision de MCU. Consulta la placa y el proyecto. No hay un compilador Egzumer incorporado al comando Bricohams V3.

Funciones y ajustes de usuario

El README documenta correccion AM, demodulacion SSB, espectro, escaneo rapido, edicion de nombre, modos de visualizacion, teclas asignables, bateria, retroiluminacion, microfono y busqueda de CTCSS/DCS. SSB aqui describe demodulacion de recepcion; no significa un transmisor SSB.

Para los conceptos RX/TX, step, ancho, SQL, tonos, VOX, TOT y bloqueo de canal, consulta configuracion comun. Usa el nombre de menu, no numeros trasladados desde F4HWN v6 o Karina. El orden y los nombres fueron modificados respecto a firmware stock.

La wiki oficial es la referencia para secuencias de teclas del build instalado:

  • Wiki y manual.
  • Publicaciones.

No se han verificado en hardware todos sus atajos ni se trasladan automaticamente a los firmwares descendientes. El README advierte de limites de rango dinamico, sobrecarga y filtros de entrada; AM fix no puede eliminar los limites fisicos. Una antena con mas señal puede empeorar recepcion en entorno RF intenso.

En ese Makefile, Clang fuerza LTO=0; con LTO=1 se fuerza OVERLAY=0. Estas reglas son propias de la base, no deben copiarse a CMake PY32 sin analizar. Activar opciones puede superar memoria o romper combinaciones; el hecho de que una clave exista no implica soporte de todas las combinaciones.

Para compilar usa toolchain y procedimiento de su README en un checkout fijado, conserva mapa, licencia y hashes, y valida el hardware V1. No se ha compilado, flasheado ni probado Egzumer durante esta incorporacion documental.

Relacion con Karina y Bricohams

Una genealogia de funciones similares no permite reconstruir las fuentes exactas de Karina. Los drivers y nombres que mencionan Egzumer tampoco son prueba. Bricohams V3 actualmente deriva de F4HWN PY32, no de este repositorio original. Un proyecto Bricohams V1 seria otra compilacion y otra validacion de hardware.
