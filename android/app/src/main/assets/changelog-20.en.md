# What's new in 1.3.0

- Profile first: radio, callsign, GPS and Maidenhead locator, CAT with connection test; the CAT screen reconnects to the profile's USB device.
- New home: Satellites, FT8/digital modes and Logbook; tools filtered by the selected radio.
- Logbook: Net Control mode (voice nets) with check-ins (station type, 5-50 W, town or locator, power supply, weather, signal, antenna/rig, traffic priority), zones, summary, CSV/JSON/ADIF export and draft autosave.
- ADIF export includes MY_GRIDSQUARE from the profile.
- RT-950 Pro: APRS TX to the radio is disabled by default (RX-only KISS link) after a firmware freeze; diagnosis documented.
