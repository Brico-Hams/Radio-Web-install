# Novedades 1.4.0

- Plantillas de repetidores para 40 países de Europa y América, ya preparadas para cada radio (RadiCodex, RT-950 Pro, UV-K5 V3, AT-D878, FTX-1), con descarga y aplicación; los países sin datos fiables figuran como pendientes de fuente. Aeropuertos de España: nueva fuente primaria (guía 101ATM, AIP de ENAIRE) con la frecuencia real 8,33 kHz, solo RX en AM.
