# Nouveautés 1.3.0

- Profil d'abord : radio, indicatif, GPS et locator Maidenhead, CAT avec test de connexion ; l'écran CAT se reconnecte à l'appareil USB du profil.
- Nouvel accueil : Satellites, FT8/modes numériques et Journal de trafic ; outils filtrés selon la radio choisie.
- Journal : mode Net Control (nets en phonie) avec check-ins (type de station, 5-50 W, commune ou locator, alimentation, météo, signal, antenne/équipement, priorité du trafic), zones, résumé, export CSV/JSON/ADIF et sauvegarde automatique du brouillon.
- L'export ADIF inclut MY_GRIDSQUARE du profil.
- RT-950 Pro : TX APRS vers la radio désactivé par défaut (lien KISS en réception seule) après un blocage du firmware ; diagnostic documenté.
