# Nouveautés 1.6.0

- Audio distant : un seul orateur à la fois ; processeur de parole et VOX désactivés par défaut.
- Sécurité TX : la TX orpheline est arrêtée, l'inhibition hors bande est désactivée par défaut et l'arrêt attend la fin de l'émission.
- Accord ATAS : un résultat non vérifié est signalé comme tel et le déclenchement du ROS agit aussi après la fin du coupleur.
- Intégration FlexRadio : les éléments sans source restent désactivés (« pendiente de fuente »).
- Correction de l'état d'appairage mTLS.
- Les résultats matériels se limitent à ce que consigne docs/PRUEBAS-Y-RESULTADOS.md.
