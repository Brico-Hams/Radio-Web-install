Scripts

Bricohams' own code, under the repository license (GPL-3.0-or-later). Run with python -I.

ScriptWhat it does
tg_kb.pyConverts Telegram Desktop JSON exports from technical groups into a local knowledge base organized by topic (firmware, flashing, calibration, mods), with a file catalog (SHA-256, target MCU from the vector table) and links. Removes authors, aliases, phone numbers, and email addresses. The result is third-party material: keep it local
test_tg_kb.pyTest of tg_kb.py using a synthetic export: python -I test_tg_kb.py
check_repos.pyReads an owner/repo list and produces a table with status, latest push, license, stars, and MCU (V3/K1 if PY32 code exists). Requires gh with a session
recover.pyFor deleted repositories: searches Software Heritage for a copy, the Wayback Machine for a capture, and forks with the same name

Typical usage:

python -I tg_kb.py salida ChatExport_grupo1 ChatExport_grupo2
python -I check_repos.py repos.txt > repos.md
python -I recover.py caidos.txt
