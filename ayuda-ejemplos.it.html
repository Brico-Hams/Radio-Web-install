Origine: release ufficiali di armel/uv-k1-k5v3-firmware-custom e muzkr/moto. Gli SHA-256 corrispondono a quelli pubblicati da GitHub per ogni file. Verifica prima dell'uso:

cd examples/firmware/f4hwn-v6.3.0
sha256sum -c SHA256SUMS

Per flashare il firmware principale: guida dall'inizio al 100 %. La versione più recente è sempre nella release di armel; queste copie sono un riferimento stabile.

Script

Codice proprietario di Bricohams, con la licenza del repository (GPL-3.0-or-later). Eseguire con python -I.

ScriptFunzione
tg_kb.pyConverte esportazioni JSON di Telegram Desktop di gruppi tecnici in una base di conoscenza locale per argomento (firmware, flash, calibrazione, mod), con catalogo di file (SHA-256, MCU di destinazione secondo la tabella dei vettori) e link. Rimuove autori, alias, telefoni ed e-mail. Il risultato è materiale di terzi: conservarlo localmente
test_tg_kb.pyTest di tg_kb.py con un'esportazione sintetica: python -I test_tg_kb.py
check_repos.pyLegge un elenco owner/repo e produce una tabella con stato, ultimo push, licenza, stelle e MCU (V3/K1 se è presente codice PY32). Richiede gh con una sessione attiva
recover.pyPer i repository eliminati: cerca una copia in Software Heritage, una cattura in Wayback Machine e fork con lo stesso nome

Uso tipico:

python -I tg_kb.py salida ChatExport_grupo1 ChatExport_grupo2
python -I check_repos.py repos.txt > repos.md
python -I recover.py caidos.txt
