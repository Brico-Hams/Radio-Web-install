# Evidencia CAT: Kenwood TS-590S/SG, TS-890S y TS-990S

## Estado

BricoHams tiene un codec puro para consultar las frecuencias VFO A/B (`FA;` y
`FB;`) y consultas de modo específicas por modelo. No abre serie/USB, no envía
comandos de escritura y no declara
compatibilidad CAT con ninguno de estos radios. No se han probado unidades
físicas.

## Evidencia consultada

Hamlib contiene descriptores separados para TS-590S/SG, TS-890S y TS-990S y usa
sus helpers Kenwood comunes para leer frecuencia. En la implementación
consultada, `kenwood_get_freq` selecciona `FA` o `FB` y convierte los 11
caracteres posteriores al comando en frecuencia. Es evidencia secundaria de
implementación; los manuales CAT del fabricante y las revisiones de firmware
aún deben cotejarse antes de habilitar un transporte.

| Orden | BricoHams | Límite |
|---|---|---|
| `FA;` | Encoder allowlist y parser de respuesta de 11 dígitos en Hz | Solo CAT ASCII; sin puerto ni confirmación física |
| `FB;` | Encoder allowlist y parser de respuesta de 11 dígitos en Hz | El VFO B debe existir en la configuración física; el codec no consulta el equipo |
| `MD;` | TS-590S/SG: consulta y parser de código ASCII en bruto | Modo actual, no selección ni lectura independiente del VFO B; no resuelve el estado DATA (`DA`) |
| `SF0;`, `SF1;` | TS-890S: frecuencia de 11 dígitos en Hz y código de modo | Respuesta de A/B validada por prefijo y ancho; no se extrapola a firmware TS-590 |
| `OM0;`, `OM1;` | TS-990S: código de modo main/sub | Parser propio; no utiliza `MD` común |
| ID del radio, meters, memorias, filtros | No implementados | Pendiente de cotejo por modelo y manual |
| CAT de escritura, PTT/TX | Bloqueados | No se habilita ninguna ruta de transmisión |

El codec reutiliza solamente el framing ASCII común de BricoHams y conserva la
respuesta dentro de un parser con límite de tamaño y terminador. No copia ni
traduce código de Hamlib.

Los modos se exponen como **códigos ASCII en bruto**, no como modos de operación
normalizados ni como capacidades confirmadas. El parser valida la forma de la
trama; una letra o dígito no acredita un modo soportado. El backend TS-590 de
Hamlib también intenta SF y vuelve a MD si falla: BricoHams no hace ese sondeo
ni adopta cambios de estado. Los manuales oficiales Kenwood no fueron
recuperables (HTTP 403) en esta revisión; el cotejo primario sigue pendiente.
