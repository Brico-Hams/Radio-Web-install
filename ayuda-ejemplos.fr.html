Origine : versions officielles de armel/uv-k1-k5v3-firmware-custom et muzkr/moto. Les SHA-256 correspondent à ceux publiés par GitHub pour chaque fichier. Vérifiez avant utilisation :

cd examples/firmware/f4hwn-v6.3.0
sha256sum -c SHA256SUMS

Flasher le firmware principal : mise en service de 0 à 100 %. La version la plus récente se trouve toujours dans la release d’armel ; ces copies constituent une référence fixe.

Scripts

Code propre à Bricohams, sous la licence du dépôt (GPL-3.0-or-later). À exécuter avec python -I.

ScriptFonction
tg_kb.pyConvertit les exportations JSON de Telegram Desktop de groupes techniques en une base de connaissances locale par sujets (firmware, flashage, étalonnage, modifications), avec un catalogue des fichiers (SHA-256, MCU cible selon la table des vecteurs) et des liens. Supprime les auteurs, pseudonymes, téléphones et courriels. Le résultat est du contenu tiers : conservez-le localement
test_tg_kb.pyTest de tg_kb.py avec une exportation synthétique : python -I test_tg_kb.py
check_repos.pyLit une liste owner/repo et produit un tableau avec l’état, le dernier push, la licence, les étoiles et le MCU (V3/K1 si du code PY32 est présent). Nécessite gh avec une session
recover.pyPour les dépôts supprimés : recherche une copie dans Software Heritage, une capture dans Wayback Machine et des forks du même nom

Utilisation typique :

python -I tg_kb.py salida ChatExport_grupo1 ChatExport_grupo2
python -I check_repos.py repos.txt > repos.md
python -I recover.py caidos.txt

Traduction de l'original espagnol. En cas de divergence, la version espagnole fait foi.
